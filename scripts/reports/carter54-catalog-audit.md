## Scope corrections
The primary repositories establish several differences from the source list:
* **Augustus** - Reimplements Caesar III, rather than Pharaoh and Cleopatra.
* **Fate/EXTELLA LINK** - The README identifies LINK as the game being researched.
* **Green Beret, Mercenary and River Raid** - The inspected repositories target ZX Spectrum rather than the source list's arcade or Atari buckets.
* **Ancient Empires** - The repository describes a mobile game, not a Game Boy Advance release.
* **Ship of Harkinian and 2 Ship 2 Harkinian** - Native ports are grouped with their Nintendo 64 games.
* **PS4/PS5 binary runners** - Compatibility layers are distinguished from decompilations and static recompilations.

## Other hosts
GitLab and Codeberg additions have verified commit dates from their public APIs. Three SourceHut projects have commit dates from their public summary pages; the current refresh script skips SourceHut URLs. Streets of Rage 2 New Era links to its project site, which does not expose a repository commit date. The R.E.L.I.V.E. site and two decomp.dev links point to games already covered by existing catalog records.

## Artwork and validation
Artwork uses exact game-title and platform matches from existing catalog entries or Libretro. New image requests were checked for a successful GET, image MIME type, real image bytes and anonymous CORS support. Image hosts that rejected the final GET checks are omitted from the added rows. Covers with no verified match remain empty rather than borrowing a similarly named game's image.

The catalog tests, full Jekyll build, generated-table checks, unique-ID checks and preserved-record comparisons are run for this change. Games themselves were not built or play-tested.
